## Как настроить phpstorm на конкретный дистрибутив

1. Откройте настройки PhpStorm: нажмите Ctrl + Alt + S (или перейдите в меню File -> Settings)
2. PHP/CLI Interpreter, нажмите на кнопку с тремя точками [...] справа.
3. В появившемся окне нажмите на иконку плюса [+] слева и выберите нужный тип дистрибутива ([+]/Local Path/) 
или среды:
- From Docker, Vagrant, VM, WSL, Remote... — если ваш проект работает в изолированной среде.
- Выберите WSL, если используете подсистему Windows для Linux, и укажите установленный дистрибутив (например, Ubuntu или Debian).
- Выберите Docker или Docker Compose, если PHP запущен в контейнере, и укажите конфигурационный файл (например, docker-compose.yml).
- Выберите Remote (SSH), если настраиваете подключение к удаленному серверу.
4. Укажите путь к исполняемому файлу PHP (для локального окружения это может быть /usr/bin/php,
   /usr/bin/php8.1 или путь к php.exe, а для контейнеров PhpStorm определит его автоматически).
5. Сохраните изменения, нажав OK. Среда автоматически просканирует версию PHP, подключенные расширения и пути к Composer.
